# for LLM/agent consumption, not human search results — it's the same content
# as its HTML page. Only the human-facing search engines are told not to
# crawl it here; `X-Robots-Tag: noindex` (set on `.md` responses in
# `tools/Caddyfile`) is what actually keeps it out of the index for engines
# that don't match one of these rules, without blocking retrieval for anyone
# else — LLM/AI crawlers are meant to fetch and use the `.md` twins freely.
