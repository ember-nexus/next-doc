---
endpoint: put-element-file
group: file-and-upload
method: put
name: Put element file
endpointUrl: /<uuid>/file
swaggerUrl: /{uuid}/file
---

Similar to `POST /<uuid>/file`, i.e. the endpoint is used to either attach a file to the referenced element or to create
a new resumable upload for it, but this endpoint does not return an error if the element already has a file attached to
it.
