---
endpoint: get-children
group: element
method: get
name: Get children
endpointUrl: /<uuid>/children
---

Endpoint returns all children of a given parent element, as well as the `OWNS`-relations between the child nodes and the
parent node.

In the following example, the response would include the nodes `Child 1` and `Child 2`, as well as the two
`OWNS`-relations, when the id of the `Parent`-node is used in the `/<uuid>/children` endpoint:

<g6-graph layout="antv-dagre-LR">
    <script type="application/json">{`
    {
        "elements": [
            { "id": "parent", "type": "Data", "data": { "name": "Parent" }},
            { "id": "child1", "type": "Data", "data": { "name": "Child 1" }},
            { "id": "child2", "type": "Data", "data": { "name": "Child 2" }},
            { "id": "owns1", "type": "OWNS", "start": "parent", "end": "child1" },
            { "id": "owns2", "type": "OWNS", "start": "parent", "end": "child2" }
        ]
    }
  `}</script>
</g6-graph>

The inverse operation is the `GET /<uuid>/parents` endpoint: [Get parents endpoint](/api/get-parents).
