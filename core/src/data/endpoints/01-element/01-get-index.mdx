Endpoint returns all elements the user has direct ownership of.
In the following example, the response would include the nodes `Data 1`, `Data 2` and `Token`:

            { "id": "data1", "type": "Data", "data": { "name": "Data 1" }},
            { "id": "data2", "type": "Data", "data": { "name": "Data 2" }},
            { "id": "token", "type": "Token", "data": { "name": "Token" }},
            { "id": "owns1", "type": "OWNS", "start": "user", "end": "data1" },
            { "id": "owns2", "type": "OWNS", "start": "user", "end": "data2" },
            { "id": "owns3", "type": "OWNS", "start": "user", "end": "token" }
        ]
    }
  `}</script>
