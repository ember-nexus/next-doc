Runs every registered background task once, in sequence. This is the command a scheduler (e.g. a
system cron job) should invoke periodically - it does not itself schedule anything or run in a
loop.

Takes no arguments or options. Currently runs [`cron:delete-expired-uploads`](/command/cron-delete-expired-uploads)
followed by `cron:reindex-files`. If cron is disabled instance-wide, the command exits immediately
without running any of the individual tasks.

<Note>
    Each task can also be run on its own, e.g. for testing or to run it on a different schedule
    than the others - see [`cron:delete-expired-uploads`](/command/cron-delete-expired-uploads).
</Note>
