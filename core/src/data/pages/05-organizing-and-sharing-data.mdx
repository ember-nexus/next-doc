# Organizing and sharing data

Organizing your data is important because:

- Organized data can be easily accessed, searched and used.
- Access management and sharing in general is simpler when data is organized.
- Performance can drop when a few nodes are collected to too many other nodes / have too many relations. Usually only a
  problem for 10.000+ relations, also called [super nodes](https://medium.com/neo4j/graph-modeling-all-about-super-nodes-d6ad7e11015b).

## General tips

- Group elements together by using parent nodes - a single node which "owns" all related elements.
- Use nested groups.
- Do not be afraid to change groupings, hierarchies etc. - Ember Nexus uses a graph database internally, so these
  operations are generally not expensive.

## Tips for multi-user installations

- Do not grant individual users access to specific elements, groups or similar. Instead, create a `Group`, add the user
  to the group, and grant the group access to the element.
